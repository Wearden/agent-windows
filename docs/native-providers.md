Firewall enum numbers are resolved using metadata obtained through the documented qualifier interfaces, rather than hardcoded guesses. The nine exact profile/property pairs are fixed in source. Absent or inconsistent metadata reports an error. Values-only arrays use the officially documented zero-based ordinal mapping; ValueMap arrays provide explicit numeric mappings. Labels outside the reviewed English enum vocabulary report an error rather than being guessed. Log capacity uses CIM uint64/VT_BSTR conversion, including bounded native string access.

The legacy commands omit `-PolicyStore`, which the official cmdlet documentation identifies as local PersistentStore configuration. The native provider implementation follows that configured-profile scope and does not claim effective ActiveStore/GPO enforcement. Runtime equivalence and qualifier availability still require future Windows validation. Password complexity and reversible-storage now use local SAM DomainPasswordInformation metadata, never password/hash or credential-store contents. The selected flags have independent typed apply/restore snapshots; see the agent README for native ABI/access and concurrency limits.
